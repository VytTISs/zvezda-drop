# Zvezda Drop v2
Полноценная демо-игра с виртуальными монетами и подарками. Нет платежей, вывода денег или реальных призов.

## Render
Build Command: `npm install`
Start Command: `npm start`
Root Directory: пусто.
Добавь `BOT_TOKEN`. Сначала можно не задавать `WEB_APP_URL`; после первого успешного запуска скопируй адрес Render вида `https://....onrender.com`, добавь его в `WEB_APP_URL` и сделай redeploy.

## GitHub
Загрузи содержимое архива в корень репозитория: `bot.js`, `package.json`, папку `public` целиком.
Баланс и инвентарь хранятся локально в браузере и пока не синхронизируются между устройствами.
Иллюстрации подарков сделаны в оригинальном стиле, это не официальные изображения Telegram Gifts.
