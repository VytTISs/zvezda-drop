# Gift Case Simulator

Бесплатный фанатский симулятор Telegram Gifts. Все подарки, открытия и монеты виртуальные.

## Публикация одним сервисом
1. Загрузи всё содержимое проекта в новый GitHub-репозиторий.
2. На Render создай **New + → Web Service** и подключи этот репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Добавь Environment Variables:
   - `BOT_TOKEN` — токен из BotFather (никому не показывай)
   - `WEB_APP_URL` — публичный HTTPS URL этого же Render-сервиса, например `https://your-app.onrender.com`
6. Нажми Deploy. После запуска открой адрес сайта — там должна открыться игра.
7. В BotFather настрой Menu Button для бота: `/setmenubutton`, выбери бота, задай текст `Открыть кейсы` и укажи тот же `https://...onrender.com` адрес.
8. Открой @Zvezdadrop_bot и отправь `/start`.

Render free-сервисы могут засыпать после периода бездействия; первый запуск после паузы иногда занимает время.

## Важно
- Не публикуй токен в GitHub и не отправляй его в чат.
- Не добавляй `.env` в репозиторий. Используй Environment Variables в Render.
- Баланс и инвентарь в этой демо-версии хранятся локально в браузере устройства.
- Визуальные подарки сейчас обозначены эмодзи; это не официальные модели Telegram Gifts.
